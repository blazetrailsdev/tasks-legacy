## Context

ActiveModel's `attribute` (`activemodel/lib/active_model/attributes.rb:35-46`)
registers the attribute and nothing more — accessor generation is deferred to
`define_attribute_methods`, which ActiveRecord calls lazily
(`activerecord/lib/active_record/attribute_methods.rb:104-125`).

trails' `attribute()` (`packages/activemodel/src/attributes.ts:198`) calls
`_defineAttributeMethod` immediately, and AR's declaration sites
(`packages/activerecord/src/attributes.ts`) additionally reset
`_attributeMethodsGenerated` and re-run `defineAttributeMethods()`. So a class
body that declares attributes has generated accessors before anything asks for
them.

This is observable. `define_attribute_methods` is gated `unless abstract_class?`
(`:113`), so an abstract class must have no per-attribute accessors — but in
trails an abstract class that declares `attribute :author_name` in its body has
them anyway, generated by the declaration rather than by the gated path.
PR 6779 hit this while restoring the abstract-gate coverage: the test had to drive
its attributes from schema reflection instead of `attribute()` calls, because
the eager path masks the gate entirely. See
`packages/activerecord/src/attribute-methods.trails.test.ts`,
"define_attribute_methods abstract gate (trails)".

## Converged shape

`attribute()` registers and stops, as `attributes.rb:35-46` does. Generation
happens only through `define_attribute_methods`, so the `unless abstract_class?`
gate is the single place that decides whether a class gets accessors.

That means the lazy trigger has to exist first: today nothing would generate for
a plain `Model.new(...)` read. Sequence this behind — or fold it into —
`0106-wide-call-set-direct-burndown/attribute-method-generation-driven-from-schema-reflection`,
which has the same prerequisite (a lazy trigger to replace an eager call site).

## Acceptance criteria

- [ ] `attribute()` in activemodel does not call `_defineAttributeMethod`.
- [ ] AR's declaration sites do not reset `_attributeMethodsGenerated` and
      re-run generation.
- [ ] An abstract class that declares attributes in its body has no generated
      accessors; its concrete subclass has them.
- [ ] The abstract-gate test can express itself with `attribute()` declarations
      rather than schema reflection.
